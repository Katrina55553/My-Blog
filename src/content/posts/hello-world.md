## 为什么开始写博客

一直想有一个属于自己的空间来记录学习和思考。与其在社交媒体上发碎片化的内容，不如静下心来写点东西。

## 这个博客的技术选型

- **框架**: Astro v5
- **样式**: Tailwind CSS v4
- **部署**: GitHub Pages

选择 Astro 是因为它默认输出零 JavaScript，非常适合内容为主的博客。
